# Цифровой ассистент

Веб-приложение для автоматической обработки аудиозаписей совещаний.  

## Библиотеки для установки (зависимости)

```
pip install streamlit
pip install openai
pip install openai-whisper
pip install torch
```

## Что нужно установить

 1. **Python 3.9+**
2. **ffmpeg** — для работы Whisper с аудио. Нужно скачать и добавить в PATH
3. **LM Studio**
4. Так же внутри **LM Studio** нужно скачать модель **Llama 3** (или скачать где-то одетльно и засунуть в **LM Studio**)
   - P.s (лучше скачать и использовать более умную модель для коректной работы!!!)
   

## Запуск

1. Открыть LM Studio
2. Перейти во вкладку **Local Server**
3. Выбрать модель **Llama 3** и нажать **Start Server**
4. Убедиться что сервер запущен на `http://127.0.0.1:1234`
5. Запустить приложение:

```
streamlit run app.py
```

6. Открыть браузер по адресу `http://localhost:8501`
